# Examples

Run any example with `pnpm dev -- --docs examples/space`
(or `npm run dev -- --docs examples/space`). Replace `space` with:

- `orbit`: API reference, code, and deep navigation.
- `fieldnotes`: illustrated journal and light theme.
- `forge`: CLI docs with automatic configuration defaults.
- `waypoint`: travel guides and nested destinations.

`space` mixes real facts with fictional travel advice and exercises hidden pages,
drafts, exclusions, custom identity, and ordered groups. Config and content edits
are watched. To test a default theme, clear `dock5.theme` in browser local storage
and reload, or use a fresh browser profile.
