# Errors

## Error response

```json
{
  "error": {
    "code": "mission_not_found",
    "message": "No mission matches this identifier."
  }
}
```

| Status | Meaning |
| --- | --- |
| 400 | Invalid request |
| 401 | Missing credentials |
| 404 | Mission not found |
| 429 | Too many requests |
