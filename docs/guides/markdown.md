# Markdown

## Supported

- Headings (`#` .. `######`)
- Lists (ordered/unordered, including nesting)
- Fenced code blocks with language highlighting and copy buttons
- Blockquotes
- Tables, reference links, and strikethrough
- Links and images (URLs sanitized)

## Tips

- Use `title:` for the page title and `sidebarLabel:` for a shorter navigation label.
- Prefer relative links for internal navigation.
